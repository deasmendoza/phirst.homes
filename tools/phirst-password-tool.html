PHirst Admin Password Tool

Turns a chosen password into its coded value for Netlify settings. Runs only on this computer — nothing is sent or saved.

1. Code one person's password

At least 8 characters, with letters and at least one number.

This coded value cannot be turned back into the password. Keep the real password private and tell it only to that person.

2. Session key (needed once)

A random secret the server uses to keep people signed in safely.
